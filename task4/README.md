# Лабораторная работа №4. Игра «Быки и коровы»

Компьютер загадывает число из 4 неповторяющихся цифр (0–9), игрок угадывает его по подсказкам:

- **бык** — цифра угадана и стоит на своём месте;
- **корова** — цифра есть в числе, но стоит на другом месте.

## Структура

| Файл            | Роль                                                        |
| --------------- | ----------------------------------------------------------- |
| `index.html`    | Разметка страницы, подключает `controller.js` как модуль    |
| `style.css`     | Оформление (есть светлая и тёмная темы)                     |
| `model.js`      | **Model** — состояние игры, генерация числа, подсчёт быков и коров, валидация |
| `view.js`       | **View** — работа с DOM: отрисовка состояния, подписка на события |
| `controller.js` | **Controller** — связывает модель и представление           |

## Как устроен MVC

- **Model** (`createModel`) хранит секретное число, массив попыток `[{ guess, bulls, cows }]` и статус игры (`playing` / `won` / `gaveUp`). Ничего не знает про DOM. Наружу отдаёт копию состояния через `getState()`; загаданное число в ней скрыто, пока игра не закончена.
- **View** (`createView`) получает состояние и рисует его: счётчик попыток, сообщение, историю, блокировку полей. История строится из массива попыток через `createElement` и `replaceChildren`, а не дописывается в `innerHTML`.
- **Controller** (`init`) принимает события от View (отправка формы, «Сдаться», «Новая игра»), вызывает методы Model и просит View перерисоваться. Если ввод некорректен, показывает ошибку вместо перерисовки.

Поток данных: действие игрока → View → Controller → Model → Controller → View.

## Что реализовано

1. Новое число генерируется при загрузке страницы и по кнопке «Новая игра» (перемешивание цифр алгоритмом Фишера–Йетса, берутся первые 4).
2. Поле ввода и кнопка «Попытка № N», где N — номер текущей попытки.
3. После каждой попытки в историю добавляется строка вида `1234 → 1 бык, 2 коровы` (с правильным склонением).
4. Счётчик попыток.
5. Кнопки «Сдаться и показать ответ» и «Новая игра». «Новая игра» доступна всегда.
6. Если число угадано (или игрок сдался), показывается сообщение, поле ввода и кнопка попытки блокируются до нажатия «Новая игра». Перезагружать страницу не нужно.

## Валидация

Попытка **не засчитывается** и показывается сообщение об ошибке, если:

- поле пустое;
- введено не ровно 4 символа или есть не цифры;
- цифры повторяются;
- такая попытка уже была.

## Технические требования

- Логика разделена на слои MVC.
- Глобальных переменных нет: код живёт в модулях, DOM-элементы запрашиваются локально, например `const inputEl = document.querySelector('#guess-input')`.
- Без IIFE и других старых паттернов инкапсуляции: изоляцию даёт сам модуль, состояние хранится в замыкании фабрик `createModel` / `createView`.
- Классы не используются.
- Генерация числа и подсчёт быков/коров написаны вручную, без библиотек.
- Canvas не используется, только обычный DOM.
