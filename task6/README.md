# Лабораторная работа №6. Змейка на Canvas

Классическая «Змейка» на чистом JS (MVC, без классов и IIFE).

## Структура
- `index.html` — canvas 400×400 (сетка 20×20 клеток по 20px), счёт и кнопка «Начать заново».
- `style.css` — оформление страницы.
- `model.js` — состояние (змейка, яблоко, счёт, статус) и правила: шаг, столкновения, рост.
- `view.js` — отрисовка на Canvas, обработка клавиш, кнопка перезапуска.
- `controller.js` — игровой цикл на `requestAnimationFrame`, точка входа.

## Как устроено
- Цикл — `requestAnimationFrame`, `setInterval` не используется.
- Скорость не зависит от частоты кадров: змейка делает шаг только если
  `currentTime - lastMoveTime >= MOVE_INTERVAL` (150 мс).
- Разворот на 180° игнорируется. Быстрые нажатия попадают в очередь (до 2), поэтому не теряются.
- Яблоко появляется только в свободной клетке. «Цена» яблока (очки и рост)
  задаётся одним объектом `FRUIT` в `model.js`.
- Столкновение со стеной или хвостом — «Игра окончена», счёт и кнопка перезапуска без перезагрузки страницы.
