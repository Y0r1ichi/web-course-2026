Одностраничный лендинг керамической мастерской «Кобальт».

## Что использовано

- Mobile First: базовые стили для мобильного, затем `@media (min-width: 768px)` и `@media (min-width: 1200px)`
- CSS Grid для сетки страницы, карточек и формы
- Flexbox для шапки, меню, карточек, полей формы и футера
- Гамбургер-меню без JavaScript: скрытый `<input type="checkbox">`, связанный с `<label>`, и псевдокласс `:checked` с соседними селекторами `+` и `~`
- Форма обратной связи со стилями `:hover` и `:focus`
- Плавные переходы (`transition`) у кнопок, карточек, полей формы и значка бургера

## Брейкпоинты

| Ширина | Раскладка |
| --- | --- |
| до 767 px | одна колонка |
| 768–1199 px | две колонки |
| от 1200 px | сетка из 12 колонок, «О студии» и форма рядом |

Бургер из трёх полосок показывается на всех ширинах. При нажатии открывается меню «Занятия», «О студии», «Запись», пункты кликабельны и ведут к разделам страницы.

## Как работает гамбургер

В шапке элементы идут строго в таком порядке: чекбокс `#menu-toggle`, затем `label.burger`, затем `nav.nav`. Чекбокс невидим и лежит поверх бургера, поэтому клик попадает в него. Когда чекбокс отмечен (`:checked`), меню показывается выпадающей панелью, а три полоски превращаются в крестик.

Ограничение: без JS меню не закрывается само после клика по пункту. Чтобы закрыть его, нужно снова нажать на бургер.

## Доступность

- Видимый фокус у кнопок, полей и бургера (`:focus-visible`)
- Бургер управляется с клавиатуры (Tab и пробел)
- Размер интерактивных элементов не меньше 44 px
- У навигации и чекбокса есть `aria-label`
