# Лабораторная работа №5. Simon

Игра «Симон говорит» на чистом JS (MVC, без классов и IIFE).

## Структура
- `index.html` — разметка: 4 кнопки-сектора, «Старт», уровень и статус.
- `style.css` — оформление на CSS Grid.
- `model.js` — состояние (последовательность, ввод, фаза) и правила игры.
- `view.js` — работа с DOM и звуком (AudioContext).
- `controller.js` — логика раунда, показ последовательности через `setTimeout`, точка входа.

## Запуск

- GitHub: https://github.com/Y0r1ichi/web-course-2026

##  Как устроено
- Показ последовательности — `async/await` + `Promise` с `setTimeout`.
- Пока идёт показ, фаза равна `showing`, и клики игнорируются.
- Все таймеры регистрируются в `createTimers`; при новой игре вызывается `cancelAll()`,
  поэтому старые и новые последовательности не накладываются.
- `setInterval` не используется.
