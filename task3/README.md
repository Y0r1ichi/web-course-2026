# Лабораторная работа №3. Основы JS и DOM: Todo-list

Интерактивный список задач на чистом JavaScript.

## Ссылки

- GitHub: https://github.com/Y0r1ichi/web-course-2026
- Сайт: https://y0r1ichi.github.io/web-course-2026/task3/

## Возможности

- Добавление задачи кнопкой «Добавить» или клавишей Enter
- Проверка на пустой ввод с предупреждением
- Отметка задачи как выполненной и удаление
- Счётчик «Осталось: N, Выполнено: M»
- Фильтры «Все», «Активные», «Завершённые»

## Как устроено

- Задачи хранятся в массиве объектов `{ id, text, completed }`
- Список отрисовывает функция `render()` на основе массива
- Разметка задач создаётся в JS через `document.createElement`
- События обрабатываются через `addEventListener`, `localStorage` не используется
