# Лабораторная работа №7. Лента постов с бесконечным скроллом

Лента постов с [jsonplaceholder.typicode.com/posts](https://jsonplaceholder.typicode.com/posts)
на чистом JS (MVC, без классов и IIFE).

## Структура
- `index.html` — поле поиска, список карточек, индикатор загрузки, блок ошибки, сообщение «Больше постов нет».
- `style.css` — оформление, CSS-спиннер.
- `model.js` — массив загруженных постов, фильтр по подстроке, правила подгрузки, функция `fetchPosts`.
- `view.js` — отрисовка карточек и статусов, определение «у конца страницы», подписки на события.
- `controller.js` — подгрузка (`async/await`, `try/catch/finally`), дебаунс поиска, точка входа.

## Запуск

- Сайт:  https://y0r1ichi.github.io/web-course-2026/task7/ 
## Как устроено
- Порция постов задаётся константой `N_PER_FETCH` (10) в `controller.js`;
  запрос: `/posts?_start=<сколько уже загружено>&_limit=N_PER_FETCH`.
- Бесконечный скролл: на событие `scroll` проверяется, что до конца страницы осталось ≤ 200px.
  Повторная проверка идёт после каждой загрузки, поэтому широкий экран заполняется сам.
- Пока идёт запрос, показывается спиннер «Загрузка…», повторные запросы блокируются.
- Когда постов больше нет (сервер сообщил общее число или вернул пустой ответ),
  подгрузка останавливается и показывается «Больше постов нет.».
- Поиск: фильтр по `title` без учёта регистра по уже загруженному массиву,
  дебаунс 300 мс на `setTimeout`/`clearTimeout`, запросов к серверу нет.
  Пока поиск активен, подгрузка приостановлена (об этом написано под полем поиска).
- Ошибки: сбой сети и `response.ok === false` превращаются в понятное сообщение
  в блоке с кнопкой «Повторить». Автоповторов нет, чтобы не спамить сервер.
